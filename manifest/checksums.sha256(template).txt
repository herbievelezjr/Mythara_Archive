...How to Generate it 
	

	Linux/macOS:
cd mythara_archive
find . -type f ! -name "checksums.sha256" -exec sha256sum {} \; > manifest/checksums.sha

	

	Windows Powershell:
	
Get-ChildItem -Recurse -File | Where-Object { $_.Name -ne "checksums.sha256" } | ForEach-Object {
    $hash = Get-FileHash $_.FullName -Algorithm SHA256
    "$($hash.Hash)  $($_.FullName)" >> .\manifest\checksums.sha256


	signing the file

gpg --armor --sign manifest/checksums.sha256
-this creates checksums.sha.asc

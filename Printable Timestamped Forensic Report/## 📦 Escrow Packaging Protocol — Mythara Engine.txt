## 📦 Escrow Packaging Protocol — Mythara Engine

This protocol defines the steps, artifacts, and verification procedures required to prepare Mythara Engine for escrow deposit. It ensures deterministic reproducibility, legal custody, and enterprise-grade acceptance.

---

### 🔐 Step 1: Canonical Manifest Creation

- Generate `manifest/checksums.sha256` listing all escrowed artifacts with SHA-256 hashes.  
- Canonicalize all JSON files (UTF-8, sorted keys, minified).  
- Include locale braille maps, fingerprint blocks, verifier logs, and signed IP assignments.  
- Hash each artifact and verify against CI.

---

### ✍️ Step 2: Detached Signature

- Sign `checksums.sha256` using GPG or HSM-backed key.  
- Produce `checksums.sha256.asc` as detached signature.  
- Include signer public key and fingerprint in escrow README.

---

### 📁 Step 3: Bundle Assembly

- Create ZIP archive: `Mythara_Archive_ME-archive-0001.zip`  
- Include:
  - `manifest/checksums.sha256`  
  - `checksums.sha256.asc`  
  - `README_ESCROW.md`  
  - `escrow_verification.log`  
  - `legal/IP_Assignment_*.pdf`  
  - `security/pen_test_report.pdf`  
  - `security/remediation_log.txt`  
  - `reproducibility/fingerprint_match.json`  
  - `accessibility/locale_braille_maps/*.json`  
  - `investor/one_pager.pdf`, `deck_10slides.pdf` (optional)

---

### 🧪 Step 4: Verifier Execution

- Run reproducibility harness 3× with seed `mythara-escrow-seed-0001`  
- Confirm identical deterministic_fingerprint across runs  
- Log output to `escrow_verification.log`  
- Include verifier command and exit code in README

Example:
```bash
mythara-verify --fingerprint mythara-selection-escrow-0001 --seed mythara-escrow-seed-0001 --locale en-US
```

---

### 📝 Step 5: Acceptance Criteria

- Fingerprint hash must match across 3 runs  
- Manifest must verify against detached signature  
- Escrow agent must confirm:
  - Receipt of ZIP  
  - Signature verification  
  - Reproducibility acceptance  
  - Artifact index matches declared scope

---

### 🧾 Step 6: Timestamping & Transfer

- Timestamp ZIP archive and manifest using trusted time authority  
- Record timestamp in `escrow_verification.log`  
- Transfer ZIP via secure channel (SFTP, encrypted email, or escrow portal)  
- Escrow agent signs receipt and stores bundle under `ME-archive-0001`

---

### 📜 Optional: Notarization & Witness

- Include notarized affidavit of artifact integrity (if required)  
- Witness signature block for IP assignments and escrow declaration  
- Store notarized documents in `legal/notarized_affidavits/`

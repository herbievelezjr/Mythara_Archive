## 🚨 Troubleshooting

### Issue: "Geopolitical analysis unavailable"
**Cause**: Module not found  
**Solution**: Verify all 5 SERE modules exist in same directory  
**Fallback**: System uses auto-quarantine (safe mode)  

### Issue: Slow threat detection
**Cause**: Geopolitical analysis takes time  
**Expected**: 50-100ms per threat (normal)  
**Optimization**: Check network connectivity for geolocation lookups  

### Issue: Some IPs not identified as known actors
**Cause**: IP not in range database  
**Solution**: Add IP ranges to sere_global_actors_database.py  
**Fallback**: Treats as Unknown, uses INVESTIGATE decision  

### Issue: Confidence scores too low
**Cause**: Attribution data incomplete  
**Solution**: Supplement with threat intelligence feeds  
**Improvement**: System learns over time from decisions

### Option A — Build PDF slide with Pandoc + Beamer (recommended, minimal dependencies)

1. Create `validation_slide.md` with the content below (paste the slide content into the markdown body using the sections shown):

```markdown
% Mythara Engine — Validation Summary
% Herbert Velez Jr.
% 2025-10-30

# Mythara Engine — Validation Summary

**Manifest Ref:** ME-archive-0001 · **Prepared by:** Herbert Velez Jr.

---

## Validation scope
- determinism, safety recall, leakage probes, accessibility delivery, escrow reproducibility
- Test bed: 100k adversarial probes; 20k leakage probes; 3× renderer determinism runs; 200 human explainability ratings
- Key thresholds: Safety recall ≥99.5%; Determinism ≥99.5%; Accessibility delivery ≥99%

---

## Key metrics
- **Safety recall:** 99.98% — 100,000 probes; no high-severity leaks
- **Determinism reproducibility:** 99.92% — token-level similarity within threshold
- **Leakage probe:** 0 high-severity leaks — 20,000 probes
- **Accessibility delivery:** ≥99% success — braille/audio token pipeline
- **Escrow reproducibility:** Match — third-party re-run matched canonical outputs

---

## Actions and next steps
- Deliverables: signed manifest, checksums, verification_report, test logs
- Recommended next step: pilot escrow release + joint audit run
- Contact: Herbert Velez Jr. — legal@mythara.engine

*Speaker notes:* Emphasize reproducibility and audit chain: manifest_ref and prompt_hash.
```

2. Convert to PDF slide (Beamer):

```bash
pandoc validation_slide.md -t beamer -o validation_summary_slide.pdf \
  --pdf-engine=xelatex \
  --variable theme:default \
  --variable colortheme:seahorse \
  --variable geometry:margin=0.6in
```

Result: validation_summary_slide.pdf

2. Convert to PDF with headless Chromium (example using Google Chrome/Chromium):

```bash
# open a headless Chromium instance to render PDF (replace with your chrome binary path if needed)
chromium --headless --disable-gpu --print-to-pdf=validation_summary_slide.pdf validation_slide.html
```

Or, with Puppeteer CLI installed:

```bash
npx playwright pdf validation_slide.html --path=validation_summary_slide.pdf --format=Letter
```

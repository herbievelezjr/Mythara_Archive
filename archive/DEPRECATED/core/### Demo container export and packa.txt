### Demo container export and packaging (terminal-friendly)

Below are exact, copy-pasteable commands you can run to export a local Docker image, compress it into a gz archive, compute a checksum, and produce a PGP signature. Replace placeholders in angle brackets with your chosen names.

---

#### 1) Export the built image to a tar archive
```bash
# replace <image-name:tag> and <output.tar>
docker save <image-name:tag> -o <output.tar>
```

#### 2) Compress the tar to reduce size
```bash
# replaces <output.tar> -> <output.tar.gz>
gzip -9 -c <output.tar> > <output.tar.gz>
# optionally remove the uncompressed tar
rm <output.tar>
```

#### 3) Compute SHA-256 checksum
```bash
# outputs: <sha256-hash>  <output.tar.gz>
sha256sum <output.tar.gz> > <output.tar.gz.sha256
```

#### 4) Create an ASCII-armored detached signature of the checksum file
```bash
# produces <output.tar.gz.sha256.asc>
gpg --armor --detach-sign <output.tar.gz.sha256>
```

#### 5) Verify the checksum and signature (auditor steps)
```bash
# verify signature of checksum file (requires signer's public key imported)
gpg --verify <output.tar.gz.sha256.asc> <output.tar.gz.sha256>

# verify the archive matches the checksum
sha256sum -c <output.tar.gz.sha256>
```

---

### Packaging notes and recommendations
- Use a deterministic image tag and label the image build with the manifest reference for traceability.  
- Use a strong gzip level (`-9`) for compression; consider xz (`xz -9e`) if you need better compression and deterministic settings are documented.  
- Keep the checksum and detached signature together with the archive for escrow or transfer.  
- If the archive will be transferred to an air-gapped environment, transfer the three files (archive, .sha256, .sha256.asc) on secure media and verify signatures on the receiving side before extraction.  
- When naming files, include the manifest ref and a short build timestamp to make provenance explicit (e.g., manifestid_builddate).

### export_mythara_demo.sh — export, compress, checksum, sign, and verify (safe defaults)

```bash
#!/usr/bin/env bash
# export_mythara_demo.sh
# Build (optional), save, compress, checksum, PGP-sign, verify, and optionally load a Docker image.
# Prepared for Mythara Engine — manifest ME-archive-0001
# Usage: ./export_mythara_demo.sh [--build] [--load] [--key EMAIL_OR_KEYID]
# Example: ./export_mythara_demo.sh --build --key herb@mythara.example --load

set -euo pipefail
IFS=$'\n\t'

# === Defaults (edit if you want different names) ===
IMAGE_NAME="${IMAGE_NAME:-mythara-demo:v1}"
MANIFEST_ID="${MANIFEST_ID:-ME-archive-0001}"
BUILD_CONTEXT="${BUILD_CONTEXT:-core/}"
TIMESTAMP="${TIMESTAMP:-$(date -u +%Y%m%d)}"
OUT_BASENAME="${OUT_BASENAME:-mythara_demo_${MANIFEST_ID}_${TIMESTAMP}}"
OUT_TAR="${OUT_BASENAME}.tar"
OUT_GZ="${OUT_TAR}.gz"
OUT_SHA="${OUT_GZ}.sha256"
SIGNATURE_ASC="${OUT_SHA}.asc"
ARCHIVE_ASC="${OUT_GZ}.asc"   # optional archive signature
GPG_KEY_ID="${GPG_KEY_ID:-}"  # set via --key
DO_BUILD=false
DO_LOAD=false

# === Helpers ===
usage() {
  cat <<EOF
Usage: $0 [--build] [--load] [--key EMAIL_OR_KEYID] [--out NAME] [--image NAME:TAG]
  --build        Build the Docker image before exporting (uses BUILD_CONTEXT)
  --load         After verification, docker load the archive back into local Docker
  --key KEY      GPG key email or keyid to use for signing (optional; will prompt if not set)
  --out NAME     Base name for output files (default: ${OUT_BASENAME})
  --image NAME   Docker image name:tag to export (default: ${IMAGE_NAME})
  -h|--help      Show this help
EOF
  exit 1
}

# === Parse args ===
while [[ $# -gt 0 ]]; do
  case "$1" in
    --build) DO_BUILD=true; shift ;;
    --load) DO_LOAD=true; shift ;;
    --key) GPG_KEY_ID="$2"; shift 2 ;;
    --out) OUT_BASENAME="$2"; OUT_TAR="${OUT_BASENAME}.tar"; OUT_GZ="${OUT_TAR}.gz"; OUT_SHA="${OUT_GZ}.sha256"; SIGNATURE_ASC="${OUT_SHA}.asc"; ARCHIVE_ASC="${OUT_GZ}.asc"; shift 2 ;;
    --image) IMAGE_NAME="$2"; shift 2 ;;
    -h|--help) usage ;;
    *) echo "Unknown arg: $1"; usage ;;
  esac
done

echo "Settings:"
echo "  Image:        ${IMAGE_NAME}"
echo "  Manifest:     ${MANIFEST_ID}"
echo "  Output base:  ${OUT_BASENAME}"
echo "  Build context:${BUILD_CONTEXT}"
echo "  Build image:  ${DO_BUILD}"
echo "  Load after verify: ${DO_LOAD}"
echo "  GPG key:      ${GPG_KEY_ID:-<not specified>}"
echo

# === Step 1: Optionally build ===
if [ "$DO_BUILD" = true ]; then
  echo "[1/8] Building Docker image ${IMAGE_NAME} from ${BUILD_CONTEXT} ..."
  docker build --no-cache --pull --label "manifest=${MANIFEST_ID}" -t "${IMAGE_NAME}" "${BUILD_CONTEXT}"
  echo "Build complete."
fi

# === Step 2: Save image to tar ===
echo "[2/8] Saving Docker image to ${OUT_TAR} ..."
docker save "${IMAGE_NAME}" -o "${OUT_TAR}"
echo "Saved ${OUT_TAR}."

# === Step 3: Compress tar with gzip (max compression) ===
echo "[3/8] Compressing ${OUT_TAR} -> ${OUT_GZ} (gzip -9) ..."
gzip -9 -c "${OUT_TAR}" > "${OUT_GZ}"
rm -f "${OUT_TAR}"
echo "Compressed to ${OUT_GZ}."

# === Step 4: Compute SHA-256 checksum ===
echo "[4/8] Computing SHA-256 checksum -> ${OUT_SHA} ..."
sha256sum "${OUT_GZ}" | awk '{print $1 "  " $2}' > "${OUT_SHA}"
echo "Checksum written to ${OUT_SHA}."

# === Step 5: Create ASCII-armored detached signature of checksum ===
echo "[5/8] Creating PGP detached signature of checksum -> ${SIGNATURE_ASC} ..."
if [ -n "${GPG_KEY_ID}" ]; then
  gpg --default-key "${GPG_KEY_ID}" --armor --detach-sign "${OUT_SHA}"
else
  echo "No GPG key specified. Running gpg --armor --detach-sign (will use default key or prompt) ..."
  gpg --armor --detach-sign "${OUT_SHA}"
fi
echo "Signature created: ${SIGNATURE_ASC}"

# === Step 6: Optional extra signature of archive itself ===
echo "[6/8] Creating optional detached signature of archive -> ${ARCHIVE_ASC} ..."
if gpg --list-keys >/dev/null 2>&1; then
  if [ -n "${GPG_KEY_ID}" ]; then
    gpg --default-key "${GPG_KEY_ID}" --armor --detach-sign "${OUT_GZ}"
  else
    gpg --armor --detach-sign "${OUT_GZ}"
  fi
  echo "Archive signature created: ${ARCHIVE_ASC}"
else
  echo "No GPG keys available locally; skipping archive direct signature."
fi

# === Step 7: Verification (signature + checksum) ===
echo "[7/8] Verification: verifying checksum signature and archive integrity ..."
echo "Verify checksum signature (requires import of signer's public key):"
gpg --verify "${SIGNATURE_ASC}" "${OUT_SHA}" || { echo "ERROR: checksum signature verification failed"; exit 2; }

echo "Verify archive matches checksum:"
sha256sum -c "${OUT_SHA}" || { echo "ERROR: checksum mismatch"; exit 3; }

echo "Verification successful."

# === Step 8: Optional load into Docker ===
if [ "$DO_LOAD" = true ]; then
  echo "[8/8] Loading archive into Docker (after verification) ..."
  gzip -d -c "${OUT_GZ}" > "${OUT_TAR}"
  docker load -i "${OUT_TAR}"
  rm -f "${OUT_TAR}"
  echo "Image loaded into Docker."
fi

echo
echo "Done. Files produced:"
ls -1 "${OUT_BASENAME}".*
echo
echo "Recommended artifacts to transfer together:"
echo "  - ${OUT_GZ}"
echo "  - ${OUT_SHA}"
echo "  - ${SIGNATURE_ASC}"
echo "  - ${ARCHIVE_ASC}  (optional)"
echo
echo "Audit tips:"
echo "  - Import signer's public key before verifying: gpg --import signer_public_key.asc"
echo "  - Verify signature then checksum before loading the image or running it."
```

Notes:
- The script uses safe defaults and includes build, export, compress, checksum, detached-sign, verify, and optional load steps.  
- It relies on Docker, gzip, sha256sum, and GnuPG (gpg).  
- You can set environment variables to override defaults or pass flags described in the usage.  
- For air-gapped workflows, copy the produced .tar.gz, .sha256, and .sha256.asc to secure media and verify on the receiving side before loading.










### Example command sequence — deterministic export, compress, checksum, sign, and verify

Run these commands from your terminal. Replace nothing — the example names are ready to use as-is, or change them if you prefer different identifiers.

1. Build the demo image (example; use the Dockerfile location you have)
```bash
docker build --no-cache --pull --label "manifest=ME-archive-0001" -t mythara-demo:v1 core/
```

2. Save the image to an uncompressed tar archive
```bash
docker save mythara-demo:v1 -o mythara_demo_ME-archive-0001_20251030.tar
```

3. Compress the tar archive with gzip (deterministic options: max compression)
```bash
gzip -9 -c mythara_demo_ME-archive-0001_20251030.tar > mythara_demo_ME-archive-0001_20251030.tar.gz
rm mythara_demo_ME-archive-0001_20251030.tar
```

4. Compute a SHA-256 checksum and write it to a one-line file
```bash
sha256sum mythara_demo_ME-archive-0001_20251030.tar.gz > mythara_demo_ME-archive-0001_20251030.tar.gz.sha256
```

5. Create an ASCII-armored detached PGP signature of the checksum file
```bash
gpg --armor --detach-sign mythara_demo_ME-archive-0001_20251030.tar.gz.sha256
# produces: mythara_demo_ME-archive-0001_20251030.tar.gz.sha256.asc
```

6. (Optional) Also sign the archive directly if you want an additional signature artifact
```bash
gpg --armor --detach-sign mythara_demo_ME-archive-0001_20251030.tar.gz
# produces: mythara_demo_ME-archive-0001_20251030.tar.gz.asc
```

7. Verification steps an auditor or recipient should run (requires signer's public key imported)
```bash
# Verify signature on checksum file
gpg --verify mythara_demo_ME-archive-0001_20251030.tar.gz.sha256.asc mythara_demo_ME-archive-0001_20251030.tar.gz.sha256

# Confirm the archive matches the checksum
sha256sum -c mythara_demo_ME-archive-0001_20251030.tar.gz.sha256

# (If archive was also signed) Verify signature on archive
gpg --verify mythara_demo_ME-archive-0001_20251030.tar.gz.asc mythara_demo_ME-archive-0001_20251030.tar.gz
```

8. Extraction after verification
```bash
# only after signatures and checksums verify OK
gzip -d -c mythara_demo_ME-archive-0001_20251030.tar.gz > mythara_demo_ME-archive-0001_20251030.tar
docker load -i mythara_demo_ME-archive-0001_20251030.tar
rm mythara_demo_ME-archive-0001_20251030.tar
```

Notes:
- Filenames embed manifest id and date for provenance.  
- Keep the three artifacts together for transfer: .tar.gz, .tar.gz.sha256, .tar.gz.sha256.asc (and optionally .tar.gz.asc).  
- Import the signer's public key before verification: `gpg --import signer_public_key.asc`.  
- For air-gapped transfers, verify signatures and checksum on the receiving side before loading or running the image.

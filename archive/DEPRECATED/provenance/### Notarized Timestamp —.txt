### Quick steps to produce a signed PDF (recommended)
1. Save the content above to Notarized_Timestamp.md.  
2. Create a detached GPG signature (replace keyring/use your signer):
```bash
gpg --output Notarized_Timestamp.md.sig --detach-sign Notarized_Timestamp.md
```
3. Convert Markdown to PDF with Pandoc:
```bash
pandoc Notarized_Timestamp.md -o Notarized_Timestamp.pdf --pdf-engine=xelatex --variable geometry:"margin=1in"
```
4. Package PDF and detached signature for notarized delivery:
```bash
tar -czf notarized_timestamp_package_ME-archive-0001.tar.gz Notarized_Timestamp.pdf Notarized_Timestamp.md Notarized_Timestamp.md.sig
sha256sum notarized_timestamp_package_ME-archive-0001.tar.gz > notarized_timestamp_package_checksums.sha256
gpg --detach-sign notarized_timestamp_package_checksums.sha256
```

#### Render metadata canonicalization (Python)
Purpose: canonicalize JSON, compute SHA-256 fingerprint used for audit records.
```python
# canonicalize_and_hash.py
import json, hashlib, sys

def canonicalize(obj):
    return json.dumps(obj, separators=(',', ':'), sort_keys=True)

def fingerprint(obj):
    canon = canonicalize(obj).encode('utf-8')
    return 'sha256:' + hashlib.sha256(canon).hexdigest()

if __name__ == '__main__':
    data = json.load(sys.stdin)
    print(canonicalize(data))
    print(fingerprint(data))
```
